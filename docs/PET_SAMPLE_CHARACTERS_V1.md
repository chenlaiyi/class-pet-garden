# Pet 样板角色设定 v1

> 本文用于把 Pet 第一阶段的 3 只样板宠物，正式定义成“可执行的角色形象标准”。
> 
> 当前目标不是做最终建模稿，而是先把：
> - 角色气质
> - 脸部方向
> - 身体比例
> - 颜色方案
> - 动作语言
> - 展示气场
> 
> 全部定清楚，后续图鉴页、主图、动画、上传素材都按这一版执行。

---

# 01. 柴柴（主陪伴角色 / 基础王牌）

## 1.1 角色定位

柴柴应该是 Pet 体系里的“默认王牌宠物”。

它不是普通小狗插画，而是那种：
- 一看就很想选它当初始宠物
- 有陪伴感
- 有一点热血
- 有一点可靠
- 像班级里最愿意陪你一起成长的伙伴

### 关键词
- 阳光
- 忠诚
- 热情
- 主角感
- 有行动力
- 小队长气质

## 1.2 视觉气质

柴柴必须具备：
- 第一眼就讨喜
- 第一眼就像主角
- 不是傻萌，而是“聪明可爱”
- 有一点英气，不要太奶

正确感觉：
- 像儿童向游戏里的初始强力陪伴宠
- 像最适合新手选择的角色
- 像会主动靠近你的宠物

错误感觉：
- 太土狗表情包
- 太憨，没有精神气
- 太幼，像幼儿插画
- 太平，没有角色识别度

## 1.3 脸部方向

### 脸型
- 脸整体偏圆，但要保留一点柴犬的利落感
- 脸颊可以饱满，但不能胖到失去精神气
- 额头稍饱满，增加主角气场

### 眼睛
- 眼睛是重点
- 形状：圆润但略带向上精神感
- 感觉：亮、聪明、有期待感
- 不能是傻大圆眼，也不能是表情包黑点眼

### 嘴鼻
- 鼻子小而立体
- 嘴型简洁，默认轻微上扬即可
- 不需要夸张笑脸
- 表情以“我在等你一起玩 / 一起升级”为核心

## 1.4 身体比例

- 头偏大
- 身体短而结实
- 胸前毛量可略强调
- 四肢短但稳
- 尾巴卷起要成为核心识别点

### 结构记忆点
- 卷尾
- 三角耳
- 胸口浅色区域
- 稳定站姿

## 1.5 配色建议

主色：
- 暖橙棕
- 奶油白

点缀：
- 耳尖 / 尾巴 / 背部可略深
- 鼻头和眼周略深色增强五官稳定性

整体目标：
- 温暖
- 阳光
- 主角感
- 经典且耐看

## 1.6 动作语言

### 待机
- 轻呼吸
- 轻微抬头
- 耳朵小幅摆动
- 尾巴节奏感明显
- 重心轻微前倾，体现主动感

### 点击反馈
- 先抬头看你
- 尾巴快速摇两下
- 身体前跃半步或轻跳
- 有“收到指令”的感觉

### 气质目标
- 不是慢悠悠
- 不是呆站
- 而是“随时准备跟你出发”

## 1.7 图鉴展示定位

柴柴在图鉴页中，应该承担：
- 第一眼最容易让人喜欢的角色
- 新用户默认最容易选中的宠物
- 可以作为封面主视觉使用

它必须是：
**亲切 + 主角 + 有记忆点**

# 02. 柯基（活力担当 / 高人气快乐角色）

## 2.1 角色定位

柯基是 Pet 体系里的“高人气快乐角色”。

它不是单纯搞笑，而是：
- 很讨喜
- 很想互动
- 很有班级气氛感
- 很适合做高活跃宠物

### 关键词
- 快乐
- 活力
- 亲人
- 社交型
- 灵动
- 自带人气

## 2.2 视觉气质

柯基必须做到：
- 一眼让人觉得有趣
- 但不是搞怪表情包
- 是一种“明亮、机灵、很会互动”的可爱

正确感觉：
- 像会在图鉴里很受欢迎的角色
- 像让小学生想一直点它看反馈的宠物
- 像班级里的开心果，但不低级

错误感觉：
- 只剩下屁股梗和搞笑感
- 傻乎乎
- 太网红表情包
- 没有高级度

## 2.3 脸部方向

### 脸型
- 更圆润一点
- 面部更柔和、更讨喜
- 比柴柴更偏“亲近感”

### 眼睛
- 眼睛略大于柴柴
- 眼神更外放、更亮
- 有“我想和你玩”的感觉

### 嘴鼻
- 嘴型可比柴柴更活泼一点
- 但仍要克制，不能裂嘴大笑
- 鼻子小而软萌

## 2.4 身体比例

- 身体更长一点点
- 腿更短
- 屁股和后腿区域要成为重要记忆点
- 站姿要有弹性感

### 结构记忆点
- 大耳朵
- 短腿
- 圆润身体
- 屁股和后背轮廓

## 2.5 配色建议

主色：
- 奶黄棕
- 奶油白

点缀：
- 耳朵和背部适度加深
- 脸中线区域尽量干净清晰，强化识别度

整体目标：
- 明亮
- 快乐
- 温暖
- 有人气

## 2.6 动作语言

### 待机
- 身体有轻微弹性上下感
- 头部轻晃
- 耳朵轻摆
- 短尾或身体后半部有节奏反馈

### 点击反馈
- 小幅蹦一下
- 身体更明显弹动
- 头部快速回应
- 有“嘿！我在！”的感觉

### 气质目标
- 节奏要更轻快
- 比柴柴更活泼
- 比仓鼠更稳
- 是阳光型互动宠物

## 2.7 图鉴展示定位

柯基在图鉴页里承担：
- 拉高整体亲和度
- 负责“可爱 + 互动欲”
- 让图鉴页变得更有生命力

它必须是：
**高人气 + 好互动 + 不低幼**

# 03. 独角兽（稀有角色 / 梦幻王牌）

## 3.1 角色定位

独角兽是 Pet 体系里的“稀有梦幻角色”。

它不能只是普通马加一根角，而是：
- 像图鉴里会让人一眼记住的稀有宠物
- 像抽卡游戏里的高品质角色宠物
- 有梦幻感，但不能俗气

### 关键词
- 梦幻
- 稀有
- 被偏爱
- 发光
- 柔和神秘
- 高级童话感

## 3.2 视觉气质

独角兽必须做到：
- 一眼知道它更珍贵
- 一眼感到梦幻
- 但不能廉价彩虹风
- 不能像儿童文具盒彩绘角色

正确感觉：
- 像图鉴中的稀有王牌
- 像活动限定 / 稀有收藏宠物
- 让孩子看到会想“这只很厉害”

错误感觉：
- 彩虹太俗
- 紫粉太腻
- 像低幼公主贴纸
- 光效太廉价

## 3.3 脸部方向

### 脸型
- 比柴柴、柯基更修长一点点
- 但仍然保持角色化大头比例
- 不能做成真实马脸

### 眼睛
- 更温柔、更梦幻
- 眼神更像“被祝福的宠物”
- 可以有更明显的高光或渐变感

### 角与鬃毛
- 角必须是核心识别点
- 不能太细，也不能太写实
- 更像高级角色符号
- 鬃毛可以有柔和流线，但不要太复杂

## 3.4 身体比例

- 头依然偏大
- 身体比普通宠物更轻盈
- 腿不能太写实，要保留角色化
- 可以有更轻的漂浮感或优雅站姿

### 结构记忆点
- 角
- 额前发束 / 鬃毛
- 梦幻色层
- 更优雅的站姿

## 3.5 配色建议

主色：
- 奶白
- 淡粉
- 柔紫
- 轻蓝

点缀：
- 角可带珍珠光或金色微点缀
- 局部高光可略强于普通宠物

整体目标：
- 梦幻
- 干净
- 稀有
- 高级

## 3.6 动作语言

### 待机
- 比普通宠物更轻、更稳
- 可有轻悬浮感
- 鬃毛轻摆
- 光点缓慢浮动
- 头部轻轻偏转

### 点击反馈
- 轻抬头
- 光点增强
- 身体轻微上扬或旋身一点点
- 像“魔法回应”，而不是普通跳动

### 气质目标
- 梦幻但克制
- 稀有但亲和
- 高级而不浮夸

## 3.7 图鉴展示定位

独角兽在图鉴页里承担：
- 稀有度天花板
- 视觉吸睛点
- 让整个图鉴系统拥有“想收集稀有宠物”的欲望

它必须是：
**梦幻 + 稀有 + 高级 + 不俗气**

# 四、三只样板的整体分工

这三只不是随便挑的，它们代表三种核心方向：

## 柴柴
代表：
- 主陪伴角色
- 默认主角宠
- 阳光成长感

## 柯基
代表：
- 高互动高人气角色
- 活跃型宠物
- 更强的学生吸引力

## 独角兽
代表：
- 稀有宠物方向
- 高价值感角色
- 梦幻系世界观上限

这三只只要立住，后面其它宠物就能按这套方式往外扩。

---

# 五、下一步执行建议

下一步建议按这个顺序继续：

1. 先把这 3 只的图鉴卡气质改出来
2. 再按这 3 只去调整主图风格标准
3. 再逐步把其它宠物往这套方向统一
4. 最后再补更真实的角色动效

# 六、当前结论

Pet 第一阶段的角色形象，不再是“做 12 个普通小宠物图标”，而是：

**先做 3 个真正成立的游戏角色宠物样板。**

这三只样板必须达到：
- 一眼像角色
- 一眼有性格
- 一眼想选
- 放进图鉴页里能撑住全站调性
