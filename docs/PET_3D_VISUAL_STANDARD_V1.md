# Pet 3D 图鉴视觉标准 v1

## 目标定义

Pet 项目第一版，不做“给小朋友看的普通可爱宠物插画”，而是做一套：

**兼顾学生、家长、学校三方审美接受度的，高质感、可收藏、偏泡泡玛特风格的 3D 宠物 IP 图鉴系统。**

第一落地场景：**图鉴页**。

图鉴页不是普通列表页，而是整套宠物 IP 世界观的第一展示窗口。它需要让人一眼感受到：
- 这不是表情包
- 这不是幼儿贴纸
- 这不是廉价卡通
- 这是有角色感、有质感、有记忆点的宠物 IP

---

## 一、核心方向

### 1.1 风格关键词

整体风格关键词：

- 泡泡玛特感
- IP 手办感
- 轻潮玩感
- 温暖陪伴感
- 圆润精致
- 有收藏感
- 有角色设定
- 有高级感

### 1.2 不是这些方向

明确排除：

- 表情包风
- emoji 风
- 幼儿园贴纸风
- 扁平儿童插画风
- 廉价游戏素材风
- 过度炫技的网游技能风
- 伪 3D 漂浮 PNG 风

### 1.3 用户感受目标

用户第一次打开图鉴页时，应该产生的感觉是：

- “这个宠物挺高级”
- “像一个正式 IP，不是随便画的”
- “有点像潮玩 / 展示柜里的角色”
- “学生会喜欢，家长不会觉得低幼，学校也不会觉得太花哨”

---

## 二、受众兼顾原则

### 2.1 学生侧

学生需要感受到：
- 可爱
- 有陪伴感
- 有想收集的欲望
- 每只宠物有鲜明个性

### 2.2 家长侧

家长需要感受到：
- 审美在线
- 不低幼、不廉价
- 有成长、鼓励、陪伴气质
- 像一个认真做的教育产品，不是闹着玩的小游戏

### 2.3 学校侧

学校需要感受到：
- 形象积极、阳光、健康
- 不浮夸、不妖艳、不奇怪
- 整体气质温暖、文明、有秩序
- 适合班级文化、激励体系、校园展示

---

## 三、宠物角色造型原则

## 3.1 总体造型基准

采用“**潮玩角色化动物**”路线，不做写实动物，也不做二维卡通头像。

要求：
- 头大于身，形成记忆点
- 身体圆润，重心稳定
- 五官简洁但不幼稚
- 四肢短而有结构
- 轮廓必须干净
- 体块关系要明确，能看出真正的“角色体积”

建议方向：
- 头身比约 **1.4:1 ~ 1.8:1**
- 优先使用“圆、椭圆、柔和弧线”构成主体
- 避免过瘦、过尖、过散的轮廓

## 3.2 面部原则

### 要做的
- 眼睛有玻璃珠 / 树脂玩具般的光泽感
- 鼻子小但有体积
- 嘴巴克制，避免夸张漫画嘴型
- 脸颊可柔和，但不能变成婴幼儿贴纸感
- 表情以“温和、呆萌、安静、高级”为主

### 不要做的
- 超大 emoji 眼睛
- 过分夸张的笑脸
- 过宽嘴巴
- 腮红贴纸式处理
- 五官挤在一起像聊天表情

### 面部气质目标
- 让人觉得“可爱但不傻”
- 像潮玩，不像儿童贴纸
- 有轻微情绪，但不吵闹

## 3.3 身体原则

身体必须支撑“这是一个真实存在的角色”的感觉：
- 胸腔、肚子、臀部有明确体积
- 四肢有承重感
- 尾巴、耳朵不是装饰贴片，而是角色结构的一部分
- 坐姿 / 站姿都要稳

不要：
- 一张平面图贴在那里
- 身体没有前后关系
- 尾巴像图标素材
- 耳朵像贴纸插在头上

---

## 四、材质与光影标准

## 4.1 材质方向

优先材质语言：
- 软胶 / 搪胶 / 树脂手办感
- 半哑光主体
- 局部高光点缀
- 柔软、细腻、干净

不建议：
- 过塑料廉价感
- 过亮金属感
- 过厚重写实毛发
- 过多复杂纹理

## 4.2 光影方向

图鉴页里每只宠物都要像被“展示灯”照着：

- 主光：柔和正前上方
- 辅光：侧后方淡彩补光
- 底部：柔和发光底座 / 阴影承托
- 环境：有少量梦幻氛围，但不能喧宾夺主

目标：
- 看起来贵一点
- 看起来像展品
- 看起来有层次

不要：
- 纯平光
- 高对比硬阴影
- 廉价滤镜感
- 五颜六色乱打光

---

## 五、动画原则

## 5.1 动画目标

动画不是为了“热闹”，而是为了让角色有生命感。

正确方向：
- 微呼吸
- 轻微重心变化
- 耳朵轻抖
- 尾巴轻摆
- 眼神/头部轻微反馈
- 特殊角色少量悬浮/光环/翅膀反馈

错误方向：
- 整张图大幅飘动
- 没有重心的上下乱晃
- 高速抖动
- 动得像廉价 H5 广告素材
- 假装 3D 实际只是整张 PNG 摇来摇去

## 5.2 动效强度标准

建议强度：
- 默认待机：**弱动效**
- hover / 点击：**中弱反馈**
- 神兽：可比普通宠物更有氛围，但仍然是“高级微动效”而不是技能表演

### 动画节奏建议
- 呼吸周期：3.2s ~ 4.5s
- 尾巴摆动：1.6s ~ 2.4s
- 轻悬浮：3.8s ~ 5.2s
- 点击反馈：0.4s ~ 1.0s 内完成

## 5.3 不同角色的动作个性

后续每只宠物动作要区分，不再共用一套假动作：

- **柴柴**：热情、挺胸、期待反馈
- **柯基**：短腿活力、尾部节奏感明显
- **金毛**：温和稳重、呼吸感更明显
- **比熊**：蓬松、轻柔、弹性反馈
- **橘猫**：慵懒、慢半拍、尾巴更有戏
- **布偶猫**：优雅、慢、轻、高级
- **小白兔**：耳朵是动作重点
- **仓鼠**：更轻快、更机灵
- **小黄鸭**：轻摆、微晃、阳光感
- **羊驼**：慢悠悠、从容、带点反差萌
- **独角兽**：轻漂浮、圣光感、梦幻但克制
- **小龙**：轻悬浮、翅膀或尾端反馈、有成长气质

---

## 六、图鉴页展示标准

## 6.1 页面定位

图鉴页不是商城商品列表，而是：

**宠物角色展示馆 / 收藏展示柜 / IP 图鉴页**

所以页面应该强调：
- 仪式感
- 展示感
- 收藏感
- 角色介绍感

## 6.2 卡片标准

每张图鉴卡片需要具备：
- 独立展示舞台
- 主角居中且有重心
- 柔和底座或展示台
- 少量点缀粒子 / 光晕 / 展示环
- 宠物名字、个性标签、简短设定文案

不要：
- 只是图片 + 名字 + 简介
- 只是卡片 hover 一下
- 画面满但没有重点

## 6.3 页面氛围

整体视觉建议：
- 奶油白 / 暖橙 / 柔粉 / 雾紫 / 轻金色系
- 干净、高级、温暖
- 可梦幻，但不能廉价

普通宠物区：
- 更生活化、亲近、阳光

神兽区：
- 更梦幻、稀有、轻舞台化
- 但仍然属于同一套世界观，不能突然变成页游风

## 6.4 详情页标准

详情页要像“角色档案页”而不是大图弹窗：
- 大尺寸主形象
- 清晰等级展示
- 个性标签
- 设定文案
- 可延展到身份卡 / 竞技场 / 大屏页

---

## 七、第一阶段执行策略

## 7.1 先做样板角色，不同时铺满 12 只

第一阶段只优先打磨 3 只样板：
- 柴柴
- 柯基
- 独角兽

原因：
- 一只普通热情系
- 一只普通亲和搞怪系
- 一只神兽梦幻系

这三只可以覆盖未来大部分风格决策。

## 7.2 先定展示语言，再扩全量

优先顺序：
1. 定视觉标准
2. 做样板角色表现
3. 定图鉴页展示结构
4. 全量扩展到 12 只宠物
5. 再复用到身份卡、竞技场、NFC 入口

## 7.3 当前实现策略判断

当前前端 CSS 动效只能作为：
- 概念验证
- 展示节奏试错
- 氛围预演

不能把它当最终资产方案。

最终需要的不是“CSS 把图片摇得更像 3D”，而是：
- 更高质量角色主图
- 更稳定的统一展示系统
- 可能的逐步资产升级（序列帧 / 分层动画 / 真 3D 渲染导出）

---

## 八、设计验收标准

后续每次新方案，都用这 8 条判断：

1. 有没有摆脱表情包感？
2. 有没有摆脱低幼贴纸感？
3. 有没有收藏型 IP 的质感？
4. 学生会不会喜欢？
5. 家长会不会嫌幼稚？
6. 学校会不会觉得不稳重？
7. 动画是不是“高级微动效”而不是乱动？
8. 放在图鉴页里像不像一个正式角色展示系统？

只要有 3 条以上答不上“是”，就不算过关。

---

## 九、v1 结论

Pet 图鉴页的后续方向，正式收口为：

**泡泡玛特式高质感宠物 IP 展示页**

不是儿童贴纸风，不是表情包风，不是单纯可爱风，而是：

- 可爱但高级
- 亲和但不低幼
- 梦幻但不廉价
- 有陪伴感也有展示感
- 能同时兼顾学生、家长、学校三方审美

---

## 十、下一步建议

在本标准之后，建议立即进入两个动作：

### 下一步 1：图鉴页框架重构
按本标准，把页面整体气质从“普通前端卡片页”升级成“IP 展示馆”。

### 下一步 2：样板角色重做
优先重做：
- 柴柴
- 柯基
- 独角兽

用这三只定义后面全部宠物的视觉基准。
