# Pet 样板角色主图提示词 / 换图标准 v1

> 用途：
> - 指导后续 3D / 插画 / AI 出图
> - 统一主图风格口径
> - 避免继续产出“幼稚、表情包、廉价、假 3D”的宠物图
>
> 当前只先服务 3 只样板角色：
> - 柴柴
> - 柯基
> - 独角兽

---

# 一、统一总提示词标准

无论做哪只宠物，主图都必须遵守以下总标准。

## 1.1 正向总提示词

建议统一基底方向：

- 高质感儿童向游戏角色宠物
- 3D character design
- collectible pet character
- polished soft material
- stylized game companion
- cute but premium
- expressive eyes
- clean silhouette
- warm cinematic lighting
- soft rim light
- high-end mobile game pet character
- friendly, magical, collectible
- full body character
- centered composition
- character showcase

如果中文描述，统一理解为：
- 高质感
- 游戏角色宠物
- 可收集
- 可养成
- 有角色感
- 有主角感
- 有温暖光影
- 有体积感
- 不低幼

## 1.2 统一负面提示词

所有宠物统一避开：

- 表情包风
- emoji 风
- 幼儿贴纸风
- 廉价页游风
- 扁平插画感
- 低质量卡通图标
- 夸张搞怪表情
- 塑料廉价感
- 过饱和彩虹色
- 过度复杂背景
- 太多文字元素
- 太写实动物毛发
- 恐怖感
- 脏乱、暗黑、攻击性太强

如果是英文负面提示词，可参考：
- emoji style
- sticker style
- cheap mobile game art
- low quality cartoon icon
- flat illustration
- meme expression
- childish kindergarten style
- over-saturated colors
- cluttered background
- awkward anatomy
- low detail face
- ugly expression

# 二、统一主图输出标准

## 2.1 构图要求

主图建议统一：
- 单角色
- 正面或 3/4 角度
- 全身可见
- 主角居中
- 轮廓完整
- 背景干净或透明背景

## 2.2 光影要求

统一光影：
- 柔和主光
- 轻边缘光
- 可有轻微舞台感
- 不要花哨背景抢戏

## 2.3 材质要求

材质方向：
- 柔软树脂感
- 高级玩具感
- 半哑光 + 局部高光
- 干净细腻

不要：
- 毛绒玩具感太强
- 真实动物照片感
- 塑料廉价感
- 纸片感

## 2.4 动作姿态要求

默认主图姿态：
- 稳定站姿
- 带一点待机生命感
- 不做大动作
- 要像角色在“等你选它”

# 六、换图验收标准

后续无论 AI 出图、外包做图、手工改图，都要用这 7 条验收：

1. 这只宠物是不是一眼像“游戏角色”而不是图标？
2. 小学生会不会第一眼想选它？
3. 有没有摆脱表情包感？
4. 有没有摆脱低幼贴纸感？
5. 五官是不是有角色气质？
6. 体块是不是成立？
7. 放进图鉴页里能不能撑住主角感？

如果 7 条里有 3 条以上答不上“是”，就不能作为正式主图使用。

# 七、建议工作流

接下来建议按这个流程做：

1. 先用本文档分别出柴柴 / 柯基 / 独角兽主图
2. 从每只里各选 2~3 张方向最对的版本
3. 再统一做风格收口
4. 最后才批量扩展其它宠物

不要一开始就 12 只一起做，否则风格会继续散。

# 八、当前结论

这份文档的目标很明确：

**先把 3 只样板角色的“主图口径”定死。**

这样后面不管谁来做图，至少不会再回到：
- 幼稚
- 表情包
- 廉价
- 假 3D

这条老路上。
