# Pet 样板角色 Prompt 包 v1

> 用途：
> 直接用于 AI 出图 / 角色试图 / 外包沟通。
>
> 规则：
> - 每只角色给 3 组 prompt
> - 同一角色保持同一大方向
> - 但分别强调不同气质切面
> - 方便快速筛选最适合的方向

---

# 五、使用建议

## 第一轮建议怎么试

建议第一轮不要一次把所有 prompt 全部混着试。

### 推荐顺序
1. 先试：柴柴 A / 柯基 A / 独角兽 A
   - 先拿三只最标准版本定大方向
2. 再试：B 组
   - 看角色张力能不能更强
3. 最后试：C 组
   - 看是否更适合整体产品气质

## 第二轮怎么选

每只角色建议留下 2 张：
- 1 张最适合当“当前主推正式版”
- 1 张作为备选风格参考

不要一开始就追求一步到位，先把“不是表情包、不是低幼、像角色”这个大方向跑出来最重要。

# 六、当前结论

这一份 Prompt 包的目标，不是立刻生成最终神图，而是：

**快速帮 Pet 跑出 3 只样板角色的正确方向。**

只要第一轮能跑出：
- 柴柴像主角宠
- 柯基像高人气互动宠
- 独角兽像稀有梦幻宠

那整条路线就基本走对了。
